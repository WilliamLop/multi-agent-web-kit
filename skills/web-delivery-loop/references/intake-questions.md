# Intake Questions

Use these questions to turn a vague website request into an executable task.

## Goal and scope

- What exact user behavior must change?
- Who is the user of this feature?
- What is in scope now?
- What is explicitly out of scope?

## Current state

- What already exists in the repo?
- What currently works?
- What currently fails or is missing?
- What environment is used for local validation?

## Constraints

- Are there design system or product constraints?
- Are there deployment or environment constraints?
- Are there data or auth dependencies?
- Is backward compatibility required?

## Acceptance and validation

- What visible behavior proves success?
- What should happen on invalid input?
- What should happen if an external dependency fails?
- What must be validated with Playwright?

## Risk scan

- What would break user trust if this fails?
- What can silently fail?
- What part is likely to become fragile if implemented quickly?
